About Me

Hello! My name is Uzair Aslam, and I am currently a 4th-semester university student. This website is a project I created as part of my Web Technologies course, where I am learning about web development, design, and interactive content.

The goal of this project is to share educational content about video games, including game reviews, AI in games, and insights into gaming mechanics. Through this project, I aim to improve my skills in HTML, CSS, and web design while creating a site that is informative and engaging for visitors.

I hope you enjoy exploring the content and find it useful for learning more about games and technology!
